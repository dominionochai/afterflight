# 8. WHAT IS EXPLICITLY OUTSIDE THE FIRST RELEASE

- Replacing JCMA's actual migration engine.
- Migrating issue data, attachments or comments.
- Rebuilding every dashboard.
- Replacing every Marketplace app.
- Repairing arbitrary third-party app configuration.
- Automatically modifying every automation rule.
- Guessing ambiguous entity mappings.
- Claiming full behavioural equivalence where the source and destination environments differ.

This keeps the project achievable.
