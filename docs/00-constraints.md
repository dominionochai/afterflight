# Confirmed Project Constraints

- Codegeist 2026 is open. Devpost deadline: December 22, 2026, 12:00 PM PST. Submission via Devpost: https://codegeist2026.devpost.com
- Atlassian ended new sales of Jira Data Center subscriptions on March 30, 2026. Source: https://www.atlassian.com/licensing/data-center/end-of-life
- Jira DC trial licenses can no longer be self-generated since March 30, 2026; requests go through Atlassian Purchasing & Licensing. Source: https://confluence.atlassian.com/adminjiraserver102/get-a-jira-data-center-trial-license-1473876392.html
- A developer license is not a free standalone substitute: it is available to existing commercial and academic self-managed license holders, and maintenance expiry is synchronized with the production product license. Cite https://www.atlassian.com/licensing/data-center.
- JCMA is free and can target a Jira Cloud Free site (10 users, 2 GB), but the Cloud Migration Trial requires an existing Commercial/Academic DC license with at least 11 users. Cite https://www.atlassian.com/migration/assess/cloud-migration-trial and https://www.atlassian.com/migration/assess/cloud-migration-trial/options.
- Therefore Phase 3 (a real reproducible DC-to-Cloud migration) is NOT achievable tonight for free. It is a 6-week task requiring either access to an existing DC license holder, a real migration someone else owns, or a clearly labelled synthetic-fixture fallback.
